# astrbot\_plugin\_eatdrink

**[用于随机推荐吃什么 喝什么 或是 吃喝什么一起] 食物推荐插件**

</div>

## 简介

`astrbot_plugin_eatdrink` 是一个随机推荐吃喝什么的插件。

## 功能&教程

- **随机推荐吃的**：
    发送 "/吃什么" 推荐吃的 吃点啥 进行随机推荐吃的
    发送 "/吃什么 烧烤" 推荐吃什么烧烤，类似的还有火锅、主食、肉菜、日料、披萨等
- **随机推荐喝的**：
    发送 "/喝什么" 推荐喝的 喝点啥 进行随机推荐喝的
    发送 "/喝什么 奶茶" 推荐喝什么奶茶，类似的还有咖啡、果汁、气泡水、甜品等
- **一起推荐吧！**：
    发送 "/吃喝什么" 随机推荐吃喝！

吃喝分类预设模板在第一次安装插件时会复制到/plugin_data/astrbot/plugin/eatdrink/下，可根据个人喜好添加
添加时记得在名称后面加上"|"管道符号来进行详细分类以启用分类推荐

> 1.6.0 起，数据文件支持 `#` 注释行，可以在 food.txt / drink.txt 里写分段说明，
> 插件加载时会自动跳过注释，不会把它们当成菜品。

> 1.3.0 起，分类关键词不再要求必须带 "/" 前缀：私聊直接发 `吃什么 川菜`，
> 或群聊 @ 机器人后发 `吃什么 川菜`，都能正确命中分类。
>
> 1.4.0 起，根据当前时间自动调整推荐策略：
> 早餐时段（05:00–09:59）优先推荐 早餐 类（包子、油条、三明治等）；
> 正餐时段（10:00–21:59）维持原全量随机；
> 深夜时段（22:00–次日 04:59）偏清淡、汤品，并附带一句「少吃一点、清淡一点更健康哦」的温和提醒。
>
> 1.6.0 起，食物库全面转向「一个人能吃完的一餐」：新增 **一人食** 分类，
> 发送 `/吃什么 一人食` 可只看套餐 / 盖饭 / 单人份面饭粥。
> 原来的单串、单碟、单碗级条目（烤金针菇、豆腐脑、油条、炒青菜、米饭…）已清理。

> 1.7.0 起，新增独立的**彩蛋库**（`egg.txt`），两个分类：
> **福瑞**（furry / 兽圈）和 **老公**（帅气的男人）。
> 发送 `/吃什么 福瑞` 或 `/吃什么 老公` 就能抽一个名字。
> 彩蛋条目**不参与随机推荐**——随手一句 `/吃什么` 永远不会抽到人名；
> 只有主库（食物 / 饮品）查不到关键词时，才轮到彩蛋库兜底，并换成彩蛋专属文案。
> 想加自己的梗，照抄 `egg.txt` 的格式追加一行 `名字|分类` 即可。

## 彩蛋库

彩蛋库是独立数据文件 `templates/egg.txt`，格式与 `food.txt` / `drink.txt` 完全一致。
第一次运行时同样会自动复制到 `/plugin_data/astrbot/plugin/eatdrink/egg.txt`，可以自由增删。
